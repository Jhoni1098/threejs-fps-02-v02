FROSTLINE is a round-based tactical FPS in three.js: Aurora attacks, Breakwater defends. Fight across a frozen harbour to the east warehouse, reach the hostage, and escort them back to the green dock ring — or stop the other team cold. Two teams of bots, a buy menu between rounds, money for kills and wins, and gunfire where stopping to aim beats spraying on the move. It runs offline from static files: no build step, no network request.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Click to play: WASD to move, mouse to look, click to fire, R to reload, B to buy between rounds, G for grenade.
